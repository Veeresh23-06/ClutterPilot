How ClutterPilot works.

Three straightforward steps with absolute safety for your originals.

01

Select Files or Folder

Drag and drop any cluttered folder or documents. SHA-256 duplicate checking and file inspection happen right inside your browser memory.

02

Local AI Context Analysis

Your on-device Ollama model (Qwen 2.5) evaluates document snippets directly on your machine. You get meaningful, context-aware filenames and category suggestions with zero cloud exposure.

03

Export Organized ZIP

ClutterPilot generates a clean, neatly arranged ZIP archive in the browser. Your original files on disk remain completely untouched.

ClutterPilot Privacy Architecture

🛡️
Verified Local-First Architecture

Every byte of your data remains on this personal computer.

1. In-Browser File Selection

When you select files, the browser loads file metadata and binary buffers directly into JavaScript memory. No network payload is created, and nothing is transmitted over the internet.

2. Client-Side Hash & Duplicate Check

Exact duplicate detection runs entirely inside your browser using the native Web Crypto API (crypto.subtle.digest('SHA-256')). It never hits an external database.

3. Local AI Inference via Ollama

When you click “Start AI Analysis”, ClutterPilot sends only bounded text snippets (truncated to ~250 characters) and file metadata to the local Express server on 127.0.0.1:3000. Express forwards this request exclusively to your local Ollama instance on 127.0.0.1:11434 running the qwen2.5:1.5b model. Zero third-party cloud APIs are contacted.

4. Zero Storage & Forensic Cleanliness

ClutterPilot writes zero user file contents to localStorage, sessionStorage, IndexedDB, cookies, or disk caches. When you close the tab or click “Reset Workspace”, in-memory references are wiped immediately.

5. Safe ZIP Generation

The organized archive is assembled completely client-side via JSZip in your browser memory and downloaded directly to your Downloads folder. Your original source files remain completely untouched.
